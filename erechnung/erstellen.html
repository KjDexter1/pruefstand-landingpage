Eigene XRechnung erstellen

Kunde, Positionen und Beträge eintragen — Sie erhalten eine XRechnung-Datei (UBL, EN 16931) zum Herunterladen, die Sie selbst per E-Mail oder Kundenportal verschicken können.

Drucken geht im Facebook-Browser nicht. Sie haben die Seite aus der Facebook-App heraus geöffnet. Deren eingebauter Browser kann nicht drucken — das liegt an der App, nicht an dieser Seite. Die Rechnungsdatei herunterladen können Sie hier aber. Zum Drucken öffnen Sie die Seite in Ihrem richtigen Browser:
  1. Oben rechts auf die drei Punkte tippen
  2. „In Chrome öffnen" bzw. „Im Browser öffnen" wählen
🧪 Testphase — aktuell kostenlos. Diese Seite wird gerade aufgebaut. Nutzen Sie sie gern regelmäßig, das hilft uns zu sehen, was gebraucht wird. Ob und was ein späteres Angebot einmal kosten könnte, steht noch nicht fest.
Nichts wird hochgeladen. Alle Eingaben bleiben in diesem Browser. Ihre Firmendaten werden nur lokal gespeichert (damit Sie sie beim nächsten Mal nicht neu eintippen müssen).
⚠ Diese Datei wurde nicht amtlich geprüft. Der Generator erzeugt eine technisch korrekt aufgebaute XRechnung, ersetzt aber keine offizielle Validierung. Prüfen Sie die Datei vor dem Versand an wichtige Kunden zusätzlich — Informationen und Prüfwerkzeuge dazu bietet die offizielle KoSIT-Seite zur XRechnung. Diese Seite ersetzt keine Steuerberatung.

⚠ Das ersetzt nicht die gesetzliche Aufbewahrung. Diese Liste liegt nur in diesem Browser und kann jederzeit verloren gehen — beim Löschen der Browserdaten, beim Gerätewechsel oder wenn das Handy Speicher freiräumt. Rechnungen müssen zehn Jahre aufbewahrt werden: Laden Sie deshalb regelmäßig alle Rechnungen als ZIP herunter und bewahren Sie die Dateien außerhalb dieses Browsers auf — auf dem Rechner, einer Festplatte oder bei Ihrem Steuerberater. Die Sicherung daneben stellt nur dieses Werkzeug wieder her; für das Finanzamt zählen die XML-Dateien aus dem ZIP.
